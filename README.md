Explicación del proyecto

Camino a la Leyenda es un proyecto web basado en el fútbol de COMEDUC. La idea es crear una página similar a las plataformas de fútbol profesional, pero enfocada en los estudiantes que participan en los equipos de fútbol de COMEDUC.

¿En qué consiste?

El proyecto consiste en crear una página donde se puedan mostrar diferentes jugadores de COMEDUC, junto con información sobre ellos y sus equipos. Buscamos adaptar la idea de las páginas de fútbol profesional a un contexto escolar.

Herramientas utilizadas

Para realizar el proyecto utilizamos:

HTML: para crear la estructura de la página.
CSS: para diseñar y darle estilo a la página.
JavaScript: para agregar funciones e interacción.
Gemini: como apoyo para desarrollar el proyecto y resolver dudas.
Claude: como apoyo para programar, revisar y mejorar el código.
